# 📱 Avito iPhone Parser Bot

Telegram-бот для мониторинга объявлений iPhone на Авито. Бот автоматически отслеживает новые объявления по заданным фильтрам и присылает их в Telegram.

## 🔧 Возможности

- Выбор модели iPhone (от iPhone 7 до iPhone 16 Pro Max)
- Выбор региона (15 популярных городов + «Вся Россия»)
- Фильтрация по минимальной и максимальной цене
- Автоматическая отправка новых объявлений каждые 2 минуты
- До 10 подписок на одного пользователя
- Управление подписками (создание/удаление)

## 🏗 Как это работает

### Архитектура

```
Пользователь (Telegram)
      │
      ▼
┌─────────────────────┐
│   Telegram Bot       │ ◄── aiogram 3 (polling)
│   (handlers.py)      │
│                      │
│   FSM: модель →      │
│   регион → цена →    │
│   подтверждение      │
└─────┬───────────────┘
      │
      ▼
┌─────────────────────┐
│   SQLite Database    │ ◄── подписки + просмотренные объявления
│   (database.py)      │
└─────┬───────────────┘
      │
      ▼
┌─────────────────────┐
│   Monitor            │ ◄── asyncio loop (каждые 2 мин)
│   (monitor.py)       │
│                      │
│   Для каждой         │
│   подписки:          │
│   1. Запрос к Авито  │
│   2. Парсинг HTML    │
│   3. Фильтрация      │
│   4. Отправка в TG   │
└─────┬───────────────┘
      │
      ▼
┌─────────────────────┐
│   Avito Parser       │ ◄── requests + BeautifulSoup
│   (parser.py)        │
│                      │
│   Построение URL →   │
│   HTTP-запрос →      │
│   Парсинг карточек   │
└─────────────────────┘
```

### Потоки данных

1. **Пользователь** нажимает «Новый поиск» → FSM проводит через шаги выбора → подписка сохраняется в SQLite.
2. **Фоновый цикл** каждые 2 минуты проходит по всем активным подпискам.
3. Для каждой подписки **парсер** формирует URL поиска Авито с фильтрами, делает HTTP-запрос и извлекает объявления из HTML.
4. Новые объявления (не отправленные ранее) отправляются пользователю в Telegram.

## 🚀 Установка и запуск

### Предварительные требования

- Python 3.10+ **или** Docker
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

### Способ 1: Запуск напрямую (Python)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/avito-iphone-bot.git
cd avito-iphone-bot

# 2. Создать виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate   # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Создать .env файл
cp .env.example .env
# Отредактировать .env и вставить свой BOT_TOKEN

# 5. Запустить бота
python bot.py
```

### Способ 2: Docker (рекомендуется для хостинга)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/avito-iphone-bot.git
cd avito-iphone-bot

# 2. Создать .env файл
cp .env.example .env
# Отредактировать .env и вставить свой BOT_TOKEN

# 3. Запустить
docker-compose up -d --build

# Посмотреть логи
docker-compose logs -f

# Остановить
docker-compose down
```

## ⚠️ Важные замечания

### Про парсинг Авито

- Авито имеет **защиту от ботов** (капчи, блокировка IP). Бот использует ротацию User-Agent и случайные задержки между запросами.
- При большом количестве подписок IP может быть заблокирован. Рекомендации:
  - Увеличить `CHECK_INTERVAL` до 300+ секунд
  - Использовать **прокси** (добавить в `parser.py`)
  - Использовать VPN/прокси-ротатор
- Структура HTML Авито может меняться — парсер может потребовать обновления.

### Про Telegram Bot Token

1. Написать [@BotFather](https://t.me/BotFather) в Telegram
2. Отправить `/newbot`
3. Указать имя и username бота
4. Скопировать полученный токен в `.env` файл
